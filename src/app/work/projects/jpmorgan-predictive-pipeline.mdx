## The work

An end-to-end analysis of JPMorgan Chase stock data in Python, built as a
pipeline rather than a notebook that runs top to bottom once:

- **A reusable load-and-clean function** — date normalisation and missing-value
  handling, written so it takes any ticker rather than being hard-coded to this
  one
- **Augmented Dickey-Fuller testing** for stationarity
- **Risk quantification** from the return series
- **A supervised linear-regression forecast**, evaluated on R²
- **Reporting charts** in seaborn

## Why the stationarity test comes first

Fitting a regression to a raw price series produces an impressive R² and means
nothing — prices trend, so a model that predicts "roughly yesterday's price"
scores extremely well while carrying no information at all.

Running the Augmented Dickey-Fuller test first is what establishes whether you
are modelling a series that can be modelled, or fitting to a trend. It is the
step that decides whether the rest of the pipeline is worth running, which is
why it sits before the model rather than in an appendix.

## What carried forward

The reusable loader is the piece that mattered beyond the assignment. The same
pattern — one function that takes a ticker and returns a clean, date-indexed
frame — is what the
[dissertation pipeline](/work/crisis-volatility-lstm-shap) is built on, where
it handles four indices across twenty years instead of one stock across five.
